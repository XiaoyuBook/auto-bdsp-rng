# About dialog logos

The existing EasyCon, Project_Xs and PokeFinder assets identify their respective
projects; their link targets and ownership are unchanged.

`friend_project_xs.png` is a cleaned derivative of this repository's existing
blue feather image (before refinement: commit `635d956`, 1254 × 1254 pixels).
The pale checkerboard was embedded in opaque pixels. It has been removed from
the alpha channel, the feather outline retained, the transparent margins cropped,
and the result reduced to 138 × 256 pixels with antialiasing. No generated or
replacement brand mark was introduced.

The About dialog uses 56px containers with 40px round logos and a 44px feather,
preserving the original aspect ratios. Contact buttons use the shared 1.8 stroke
vector icon engine instead of platform-dependent emoji.
