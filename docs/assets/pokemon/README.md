# Pokemon menu icons

Source: https://github.com/PokeAPI/sprites/tree/712e6d9f915a1d2bdfbe991d04eea75e3ad950e7/sprites/pokemon/versions/generation-viii/icons

These unmodified Generation VIII menu sprites are bundled for the 47 species already supported by the static encounter data. They are decorative; selection and RNG behavior use the existing encounter records. No runtime downloads. Missing assets use a neutral line icon.
