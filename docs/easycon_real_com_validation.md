# EasyCon 真实 COM 验证清单

> 目的：验证 Python 原生 EasyCon 的真实串口、长期连接、共享画面和脚本兼容性。没有真实单片机、采集卡和游戏画面时，只能完成自动测试，不能把 mock 结果写成实机验收。

## 真实 COM 最小脚本验证流程

- [ ] 在 Seed 捕捉页连接采集卡，确认主预览持续显示且画中画可独立开关识别框。
- [ ] 刷新串口列表，记录目标串口，例如 `COM7`。
- [ ] 关闭可能占用串口的 EasyCon GUI、VS Code 插件或其他串口工具。
- [ ] 如当前单片机固件要求，先按一次 reset。
- [ ] 在伊机控页点击“连接伊机控”，确认完成握手并保持连接。
- [ ] 生成最小脚本：

```text
WAIT 50
```

- [ ] 通过当前 Python 原生后端运行最小脚本。
- [ ] 记录 stdout、stderr、exit code、开始时间、结束时间、耗时、源脚本名称和串口。
- [ ] 若失败，按错误类型记录：串口占用、未 reset、连接超时、脚本编译失败或其他。
- [ ] 脚本结束后再次运行同一脚本，确认串口没有断开或重新握手。

## 真实 COM 无参数脚本验证清单

- [ ] `BDSP测种.txt`
- [ ] `BDSP地下测种.txt`

每个脚本记录：

- [ ] 运行前后确认未出现 `script/.generated` 或临时 `.ecs` 运行快照。
- [ ] 真实 COM 口。
- [ ] 是否需要运行前 reset。
- [ ] exit code。
- [ ] stdout/stderr 是否完整进入 UI 日志。
- [ ] 脚本实际按键效果是否符合预期。
- [ ] 运行结束后串口是否保持连接，下一次运行是否直接复用。

## 真实 COM 带参数脚本验证清单

- [ ] `翻图鉴.txt`：填写 `_翻几次`。
- [ ] `地下翻图鉴.txt`：填写 `_翻几次`。
- [ ] `过图鉴.txt`：填写 `_过几次`。
- [ ] `地下过图鉴.txt`：填写 `_过几次`。
- [ ] `玫瑰公园.txt`：填写 `_闪帧`，确认 `_自动撞帧`、`_等待时间`。
- [ ] `谢米.txt`：确认 `_闪帧`、`_自动撞帧`、`_等待时间`，重点观察脚本内双等待逻辑。

每个脚本记录：

- [ ] 参数输入值。
- [ ] 写回后的脚本文本是否保留注释和缩进。
- [ ] 运行前后确认未出现 `script/.generated` 或临时 `.ecs` 运行快照。
- [ ] 真实 COM 口。
- [ ] 是否需要运行前 reset。
- [ ] exit code。
- [ ] stdout/stderr 是否完整进入 UI 日志。
- [ ] 实际游戏内效果与参数含义是否一致。
- [ ] 需要修订的参数说明。

## 长期连接与共享画面记录

- [ ] 连续运行脚本时是否始终复用同一个串口连接。
- [ ] OCR、Seed 捕捉、画中画和 `.IL` 搜图并发读取时是否互不阻塞。
- [ ] 搜图框关闭后是否只影响对应预览，其他消费者拿到的原始帧是否保持无标注。
- [ ] 采集卡停帧超过 1 秒时是否停止脚本并明确报告视频源故障。
- [ ] 失败时 UI 是否明确提示检查串口、reset 和占用情况。
- [ ] 只有主动断开视频源、主动断开伊机控或退出主程序时，相关长期资源才被释放。
