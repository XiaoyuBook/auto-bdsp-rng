# 自动定点乱数工作区改版

交付日期：2026-09-09。实现基于当前 PySide6 源码，改造范围为 `AutoRngPanel`。

新版将配置与执行结果分开阅读：左侧保留目标和策略，右侧按“运行现场 → 本轮目标 → 任务脚本”排列。默认直接显示六项脚本；开始运行后自动收起脚本编辑区，让当前帧、启动距离和锁定候选留在首屏。截图来自真实 Qt 窗口，验收用状态和候选是演示数据，不表示设备已连接或实际完成撞闪。

## A. 现状诊断

依据：`AGENT_PROJECT_CONTEXT.md`、`auto_rng_panel.py`、运行中的完整主窗口截图，以及现有 UI 回归测试。没有以使用频率统计或访谈为依据；将自动定点页作为核心页，是根据产品用途、首页顺序和完整自动流程作出的选择。

| 优先级 | 具体位置 | 已确认的问题 | 对用户的影响 | 本次修改 |
| --- | --- | --- | --- | --- |
| 必须修正 | 工具栏与运行现场标题 | 缺少必需脚本时，上方提示待配置，运行现场仍显示“准备就绪” | 对能否开始形成矛盾判断 | 缺项显示“待完成配置”；齐全显示“等待开始 / 配置已就绪”，保留顶部真实设备状态 |
| 必须修正 | 任务脚本区域 | 默认折叠六项脚本，工具栏只显示缺少数量 | 用户需要先展开，再查找缺少的字段 | 默认展开；直接显示缺项名称；字段文字标注“待选择”；“补全脚本”展开并聚焦首个缺项 |
| 必须修正 | 本轮目标区域 | 候选表位于整个脚本编辑区之后 | 运行中展开脚本，会把需要监看的候选挤到页面下方 | 候选固定放在运行现场下方；脚本区域置后，运行时首次自动收起 |
| 视觉与密度优化 | 运行现场卡片 | 固定 300px 高度分配给等待状态；说明文字有最大高度限制 | 等待状态占较多高度，长错误说明又可能截断 | 最小 220px，自然排版；较长说明增高；正文允许换行，不设置最大高度 |
| 可辨识性优化 | 未到达阶段、候选空状态 | 灰色小字使用 `#7A8A82`、`#8A9891` | 状态文字相对背景较浅 | 统一为 `#596C62`；保持数字、步骤名称、完成勾和失败感叹号，补充输入焦点边框 |

代码检查同时确认了“正在停止”被一般运行状态覆盖的分支顺序问题，本次将停止请求优先展示。负剩余帧数仍保留原始值，说明改为“启动点已过去…”，避免“还需过负数帧”的歧义。

## B. 推荐方向

采用紧凑的原生桌面工作区。延续白色主区域、浅灰绿配置区和绿色执行操作，不增加渐变、玻璃效果、侧边大导航或装饰图表。

配置时，用户可以直接看到目标、搜索范围、delay 与六项脚本，并按文字提示补齐缺项。运行时，视线按阶段、当前/目标帧、启动距离、本轮候选自上而下移动；详情仍通过“轮次记录”“查看目标数据”“查看日志”进入原工作区。

## C. 核心页面规格

所有尺寸均为 Qt 逻辑像素，跟随已有应用倍率整体缩放。

| 区域 | 位置与尺寸 | 内容与行为 |
| --- | --- | --- |
| 应用框架 | 原 1150 × 900 逻辑画布；顶栏 56px；底栏 30px | 六个主标签、视频源、伊机控和帮助入口保留 |
| 运行工具栏 | 页面顶部 56px | 左侧运行模式/次数/调试；中部配置或运行状态；右侧 OCR、分阶段开始、停止 |
| 任务配置 | 左侧固定 326px；左右内边距 18px；常规间距 13px | 原目标设置及多组 OR 筛选、搜索范围、delay、最大等待、更多策略、保存全部保留 |
| 运行现场 | 右侧首区，水平内边距 18px | 标题右侧“轮次记录”；状态面板最小 220px；内部水平内边距 16px |
| 状态面板 | 当前阶段和轮次在顶部；说明在第二行 | 待配置时显示“补全脚本”；其后为六阶段、三列指标、本轮冻结 delay 和目标数据入口 |
| 本轮目标 | 紧跟状态面板 | 表头 30px、行高 30px；最多显示五行高度；超过时表内滚动；原最多 20 条与锁定行置顶逻辑不变 |
| 任务脚本 | 候选区域之后 | 标题行统一放就绪提示、刷新、保存状态、保存脚本选择、展开/收起；移除重复标题 |
| 脚本字段 | 原 3 行 × 2 列；列间距 16px；行组间保留 6px 空隔 | 测种/过帧、撞闪/过场、反查/逃跑；下拉框 32px 高，旁边 32 × 32px 编辑入口 |
| 脚本折叠状态 | 仅替代六项编辑字段 | 显示已选择数量与用途；完整路径保留在工具提示；展开按钮始终可达 |

影响习惯的改动有两项：本轮候选移至脚本之前；脚本默认展开，第一次进入运行阶段时自动收起。之后每次进度更新不会再次强制收起，用户可随时展开查看或配置下一次任务。

没有修改的业务规则包括：分阶段启动、脚本校验、目标条件含义、循环行为、帧数与 delay 计算、OCR、反查、逃跑续搜、配置保存时机、脚本编辑器的未保存确认，以及共享设备连接。

### 窗口适配

继续使用已有 `ui_scale.py` 的整体倍率和自动适应屏幕策略，不引入新的断点或改写固定逻辑画布。普通配置下无需整页滚动。高级策略使用左侧内部滚动；运行中手动展开全部脚本时，右侧保留内部滚动，候选始终排列在脚本之前。表格与目标条件区保留原内部滚动。

长错误文本允许自然增高，必要时在右侧滚动查看全文。不会缩小字号或截断原始错误来维持固定卡片高度。

### 状态与键盘

| 状态 | 显示与操作 |
| --- | --- |
| 缺少脚本 | 工具栏点名缺项；对应字段浅黄底、“待选择”文字；补全按钮定位首个缺项 |
| 配置齐全 | “配置已就绪 / 等待开始”；说明仍提醒确认顶部设备；不代替原启动校验 |
| 未保存 | 原配置区与脚本区分别显示未保存状态；保留原保存按钮及启动自动保存 |
| 准备 | “正在准备 · 请稍候”；按原生命周期禁用开始与刷新 |
| 运行 | 展示真实阶段、轮次、原始数值；锁定候选带“已锁定”文字；开始禁用、停止可用 |
| 停止中 | “正在停止 · 请稍候”，不再被一般运行消息覆盖；停止按钮禁用防重复请求 |
| 完成 | “流程已完成 · 可查看轮次”；不把完成显示为已出闪 |
| 失败 | 红色状态面和“失败/配置错误”；显示实际错误文字，详细日志入口保留 |
| 无候选 | 区分未开始、搜索中、未找到、失败无候选和流程结束；候选计数始终保留 |
| 禁用 | 延续原控件禁用与刷新占用规则；逃跑续搜未启用时逃跑脚本保持禁用 |

脚本字段提供可访问名称和标签关联；展开按钮的可访问名称跟随状态变化。候选表可获得键盘焦点并使用原生滚动，不改变候选锁定逻辑。焦点使用 `#176B97` 的边框，按钮同时采用内部虚线提示，不仅依赖颜色表达缺项、完成或失败。

## D. 精简设计规范

### 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `SURFACE` | `#FFFFFF` | 工作面、输入框 |
| `SURFACE_MUTED` | `#F6F8F7` | 配置栏、空闲状态面 |
| `TEXT` | `#24312D` | 标题、主要文字、数值 |
| `TEXT_SECONDARY` | `#596C62` | 说明、未到阶段、空状态 |

| `WARNING` / `WARNING_SOFT` | `#906423` / `#FFF7E8` | 缺项与未保存 |
| `ERROR` / `ERROR_SOFT` | `#AC4B42` / `#FFF4F1` | 错误与失败 |
| `FOCUS` | `#176B97` | 键盘焦点 |

色彩定义及 QSS 替换函数位于 `ui/workspace_theme.py`，自动定点页的主要色彩实际从这些 token 解析。其他页面可逐步复用，不需要一次重写全局主题。

### 字体与几何

- 继续使用 Microsoft YaHei UI / Segoe UI 和项目已有回退字体；没有新增字体依赖。
- 分区标题 15px/600；运行阶段标题 18px/700；关键数值 24px/600；表单与按钮 13–14px；辅助说明 12px。
- 当前、目标、距离、本轮 delay 保持项目的表格数字字体设置和原单位；Seed 页的等宽字体不变。
- 常规控件高 32px；运行工具栏控件高 34px；小图标操作区域 32 × 32px。
- 表单沿用 13px 节奏；右侧分区间距 10px；脚本两列间距 16px；主区域左右内边距 18px。
- 输入、按钮、小状态标签圆角 5px；运行状态面圆角 7px；常规边框 1px；不增加阴影。
- 主执行按钮沿用绿色实底；设置和保存按原状态显示；导航链接保持轻量；危险停止操作保留红色文字和明确“停止”。
